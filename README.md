# DMIT 注册教程：拼音填姓名、邮箱验证到支付宝付款，新手一次走完整个下单流程

大部分人卡在 DMIT 注册这一步，不是不会点按钮，而是被几个小坑绊住：姓名填了中文提交报错、邮箱验证码没收到、付款页突然要求补手机号、注册完进后台发现看不到便宜套餐。DMIT 用的是标准 WHMCS 面板逻辑，顺序是「先建账号 → 再选套餐 → 最后结算」，跟国内主机商那种「选好机器一路付钱再顺手注册」的习惯不太一样。

这篇把注册到付款整条链路拆开讲，包括几个只在实际操作里才会遇到的位置。

## 注册前先准备好三样东西

- **一个能正常收信的邮箱**。Gmail、Outlook、QQ 邮箱都可以用，验证码会发到这里。临时邮箱、一次性邮箱容易收不到信，后面找客服也麻烦。
- **一种能付美元的方式**。DMIT 主流是支付宝、PayPal 和信用卡，其中支付宝对国内用户最省事。
- **姓名拼音**。注册页的 First Name 和 Last Name 只认英文字母。你把中文字贴进去，表单校验会直接挡下来。

顺手说一下：DMIT 成立于 2017 年，机房在美国洛杉矶、中国香港和日本东京，全部跑 KVM 虚拟化和 AMD EPYC 平台，线路分 Premium（CN2 GIA 方向）、Eyeball（CMIN2 方向）、Tier 1（国际 BGP）和带防护的 Premium Secure 四条产品线。这些信息对注册本身没影响，但你在第 5 步选套餐时会用到。

## 第一步：进入官网，找到 Sign Up

打开首页，右上角有登录入口，旁边就是注册按钮。首页默认是英文界面，习惯中文的话可以切一下语言再操作。

👉 [打开 DMIT 注册页，开始建账号](https://www.dmit.io/aff.php?aff=12046)

## 第二步：填写注册表单，注意协议要滚到底

注册区要填的东西不多：

1. First Name（名）和 Last Name（姓），都填拼音；
2. 邮箱地址，这个后面会直接当作你的登录账号；
3. 密码，建议别用你常用邮箱的同款密码；
4. 勾选人机身份验证，把验证码过掉。

接下来是服务条款那个框。勾选之后会弹出一个条款窗口，**需要你把滚动条拖到最底部，等倒计时结束**，右下角的 Close 按钮才会生效。很多人以为勾一下就行，结果点不动，原因就在这里。

全部确认后点 **Create Your Account** 提交。

## 第三步：邮箱验证码这一步最容易漏

提交成功后不会直接进后台，而是跳到一个验证页面。点击发送验证码按钮，去刚填的邮箱里找那封 DMIT 邮件，把验证码复制过来填进去，点 Confirm。

几点实操心得很：

- 邮件可能在垃圾箱里，先翻一下推广邮件和垃圾邮件文件夹；
- 验证码有时效，收到了就尽快填；
- 如果几分钟都没收到，可以回到页面重新发送一次，别重复注册新账号。

## 第四步：后台看不到套餐？点 Order Now

验证通过后进入用户中心。这时候账号里还没有任何服务，页面会显示 **No Products/Services Ordered, Order Now**。点这个链接就进套餐选购页了。

> 提醒一句：DMIT 的一部分低价套餐和限量特价机不会挂在首页展示位，需要登录后从产品页进入才看得到。所以先注册再挑机器，比先挑机器再注册要顺。

## 第五步：三条线路怎么区分

进产品页后先选机房，再选网络类型。这一步选错了，后面配置再对也没用。

| 线路系列 | 线路特征 | 大致适合谁 |
| --- | --- | --- |
| Premium（Pro） | 中国方向优化，洛杉矶侧回程走 CN2 GIA | 主要用户在中国大陆，对延迟和稳定性敏感 |
| Eyeball（EB） | CMIN2 及中国方向优化路由，同配置月流量通常更大 | 联通、移动用户，预算比 Pro 低一档 |
| Tier 1（T1） | 国际 BGP，不做中国大陆专门优化 | 面向海外用户的项目、中转、开发测试 |
| Premium Secure（sPro） | CN2 GIA 加高防能力 | 建站且有 DDoS 防护需求 |

一条实用的判断：你不需要中国大陆方向的优化，就别为 Premium 多付那笔钱，Tier 1 的年付门槛要低得多。反过来，如果你的访问者主要在国内，选 T1 大概率会失望。

## 第六步：配置页要填的四件事

选好套餐点进去，配置页从上到下是这几项：

- **付款周期**：月付、季付、半年付、年付都支持。周期越长折下来单价越低，但新用户建议先用月付或季付试一下线路，满意了再续长周期。
- **root 密码**：设置服务器登录密码，用复杂一点的。
- **操作系统**：常见 Linux 发行版都能选，DMIT 不提供 Windows。以后打算装宝塔或 1Panel 的，Debian 或 Ubuntu 更省事。
- **附加配置**：额外 IPv4、额外内存、额外系统盘、IP Guarantee+ 这类选项都在这一屏，全部单独计费，价格随线路不同，配置页会实时显示。没有明确需求就维持默认。

填完点 Continue 进购物车。

## 第七步：优惠码要在购物车页验证

购物车页面有个 Apply Promo Code 输入框，把码填进去点 Validate Code，价格会当场刷新。DMIT 的码基本都绑定「产品线 + 付款周期」两个条件，用错组合会直接提示无效。

## 第八步：付款方式与两个常见卡点

结算页选支付方式，然后点 Complete Order。三个卡点提前说：

**手机号验证。** 部分下单流程会要求填写手机号并做短信验证，填个真实能收码的号码，别随手写一串数字。

**PayPal 汇率。** 如果 PayPal 默认按人民币结算，建议手动切成美元支付。PayPal 自己的汇率通常比银行牌价差一截，同样一笔单子会多花几十块。

**信息一致性。** 注册时如果只填了姓名，走 PayPal 付款可能提示用户信息不完整，回后台把地址、国家这些补齐就能继续。填写不必逐字真实，但逻辑要自洽，比如选了美国，州、城市、邮编要对应得上。

付款成功后系统自动开通，机器信息会发到注册邮箱，一般在几分钟到十几分钟之间。

## 注册完成后用户最常问的几件事

**能不能退款？** 可以。新订单 3 天内、流量使用不超过 30GB，可以申请全额退款；30 天内按剩余价值部分退款。退款可以选退回账户余额或原支付方式，退回余额不收手续费，退回原路要扣支付网关的费用，支付宝这条路径因为手续费会返还，实际不收。官方处理时间通常在 48 小时内。注意被 DDoS 攻击、以「网络不够好」或 IP 归属地为理由申请，都不在退款范围内。

**IP 被墙了怎么办？** Pro 和 Eyeball 系列满足条件可免费更换：实例购买满 7 天、距离上次更换（含付费更换）满 15 天、ICMP 和所有 TCP 端口都被屏蔽、剩余有效期不少于 7 天。不满足免费条件也可以付费换，每次 5 美元，购买满 24 小时、间隔 24 小时即可申请。Tier 1 系列只支持付费更换，间隔要求是 3 天。所有情况下 IP 都是系统随机分配，不能指定段位。

**付款后多久能用？** 一般几分钟到十几分钟。登录用户中心，在服务列表里能看到实例和 IP，首次进入会提示下载 SSH 私钥，注意私钥只能下载一次，错过了要重新生成。用 Xshell、PuTTY 这些客户端连接时用户名填 root，密码用你配置时设置的那个。

**账号能不能改邮箱？** 可以，走工单流程处理过户。

## 最后给三条实在建议

第一，如果你只是第一次试 DMIT，别一上来就买年付。先月付一台洛杉矶 Pro TINY 或 EB TINY，跑几天看看晚高峰的实际表现，满意再续长周期并把优惠码叠上。

第二，注册时邮箱一定要填对，它是你的登录账号，也是接收验证码和机器信息的唯一通道，改起来要走工单。

第三，看到 Out of Stock 别急着换家。DMIT 是卖完下架、等下一批硬件到位再补货的模式，节假日和月末比较容易刷到货，热门套餐几小时内售罄是常态。

整个流程走下来其实就八个步骤，真正容易卡住的只有三处：条款窗口要滚到底、邮箱验证码要填对、手机号和支付信息要一致。把这三个地方过掉，剩下的就是挑一台符合预算的机器。
